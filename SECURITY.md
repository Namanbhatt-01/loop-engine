## Reporting a Vulnerability

Loop Engine Core executes untrusted code inside sandboxed environments. We take sandbox escapes, path traversal vulnerabilities, and circuit breaker bypasses with the utmost severity.

**Do not report security vulnerabilities via public GitHub issues.**

Instead, please send an encrypted or direct email to:
📧 **the.namanbhatt109@gmail.com**

Please include:
1. Detailed description of the vulnerability or sandbox escape vector.
2. Minimal Reproducible Example (PoC script).
3. Potential impact on the host system or network environment.

We will acknowledge receipt within 48 hours and work with you on a coordinated disclosure timeline.
